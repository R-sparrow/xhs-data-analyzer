## 10. 封面点击率的实际读取形式

`封面点击率`读取为小数形式的 `float64`，不是字符串，也不是已经乘以 100 的百分数。

实际示例：

```python
df.loc[0, "封面点击率"]
# np.float64(0.16)
```

因此：

- `0.16` 表示 16%
- `0.181` 表示 18.1%
- `0.114` 表示 11.4%

## 12. 首次发布时间的读取类型及转换注意事项

`首次发布时间`当前由 pandas 读取为 `str`，内容采用以下中文日期时间形式：

```text
2026年10月01日20时19分42秒
```

如果后续需要进行日期筛选、排序或时间计算，需要显式转换为 datetime。与当前数据格式对应的转换方式为：

```python
df["首次发布时间"] = pd.to_datetime(
    df["首次发布时间"],
    format="%Y年%m月%d日%H时%M分%S秒",
    errors="coerce",
)
```

使用 `errors="coerce"` 时，无法按该格式解析的值会转换为 `NaT`，因此转换后应检查是否出现 `NaT`。

## 13. 推荐的 pandas 读取参数

```python
import pandas as pd

df = pd.read_excel(
    "data/笔记列表明细表.xlsx",
    sheet_name="Sheet1",
    header=1,
    usecols="A:M",
    engine="openpyxl",
)
```

参数说明：

- `sheet_name="Sheet1"`：明确读取已经确认的工作表。
- `header=1`：使用 Excel 第 2 行作为表头，并跳过第 1 行说明。
- `usecols="A:M"`：仅读取已经确认的 13 个数据列。
- `engine="openpyxl"`：读取 `.xlsx` 文件。
