## 5. 时间字段的读取类型和格式

所有时间字段均被 pandas 读取为 `str`，没有自动读取为 datetime：

| Sheet 类型 | 字段 | 实际格式 | 示例 | dtype |
|---|---|---|---|---|
| 按天 | `日期` | `%Y年%m月%d日` | `2026年09月26日` | `str` |
| 按小时 | `时刻` | `%Y年%m月%d日%H时` | `2026年09月26日22时` | `str` |

如后续需要时间运算，可分别按已确认的实际格式转换：

```python
daily_df["日期"] = pd.to_datetime(
    daily_df["日期"],
    format="%Y年%m月%d日",
    errors="coerce",
)

hourly_df["时刻"] = pd.to_datetime(
    hourly_df["时刻"],
    format="%Y年%m月%d日%H时",
    errors="coerce",
)
```

转换后应检查 `errors="coerce"` 是否产生 `NaT`。

## 7. Sheet 之间的结构共性和差异

### 共性

- 都是两列结构。
- 表头都位于第 1 行。
- 都没有说明行、合并单元格、整行空行、隐藏行列或公式。
- 当前实际数据均没有单元格缺失值。

### 差异

- `基础数据总览`采用“指标/数值”的纵向键值结构，共 13 个指标。
- 5 个按天 Sheet 采用“日期/指标值”结构，各有 7 条数据。
- 2 个按小时 Sheet 采用“时刻/指标值”结构，各有 62 条数据。
- 按天时间字段名为`日期`，按小时时间字段名为`时刻`。
- 曝光数、观看数和时间序列涨粉数读取为 `int64`。
- 按天封面点击率、按天和按小时观看时长读取为带单位字符的 `str`。
- 总览的`数值`列统一读取为 `float64`，即使其中部分指标在业务含义上是计数。

## 9. 推荐的 pandas.read_excel() 参数

所有 Sheet 的表头均在第一行、实际数据均在 A、B 两列，因此通用读取方式为：

```python
df = pd.read_excel(
    "data/弃医之后的生活（74）-数据明细表.xlsx",
    sheet_name="实际 Sheet 名称",
    header=0,
    usecols="A:B",
    engine="openpyxl",
)
```

每个 Sheet 的具体参数：

| Sheet | `sheet_name` | `header` | `usecols` | `engine` |

| 曝光数（天） | `"曝光数（天）"` | `0` | `"A:B"` | `"openpyxl"` |
| 观看数（天） | `"观看数（天）"` | `0` | `"A:B"` | `"openpyxl"` |
| 封面点击率（天） | `"封面点击率（天）"` | `0` | `"A:B"` | `"openpyxl"` |
| 平均观看时长（天） | `"平均观看时长（天）"` | `0` | `"A:B"` | `"openpyxl"` |
| 平均观看时长（小时） | `"平均观看时长（小时）"` | `0` | `"A:B"` | `"openpyxl"` |
| 涨粉数（天） | `"涨粉数（天）"` | `0` | `"A:B"` | `"openpyxl"` |

## 10. 其他已确认的注意事项

- `openpyxl` 读取时提示工作簿没有默认样式定义，并会应用 openpyxl 的默认样式；该提示没有阻止数据读取。
- `基础数据总览`的指标名实际存在尾随空格。如果后续按指标名匹配，需注意这些空格。
- 按小时时间序列没有覆盖区间内每一个自然小时，不应把“没有该小时的记录”直接当作数值 0。
- `基础数据总览`中的 0.0，以及时间序列中的整数 0 和字符串 `0s`，均为实际记录值，不是缺失值。
