# 小红书创作者数据分析器（XHS Data Analyzer）

这是一个使用 Python 开发的学习型项目，目标是帮助创作者理解笔记表现和数据变化。

未来计划分析小红书创作者后台导出的笔记列表明细表和单篇笔记多 Sheet Excel 数据，包括数据快照、按天或小时的指标变化、笔记生命周期曲线和不同笔记之间的表现比较，后期探索 AI 数据分析。

项目目前处于早期开发阶段，仅完成 Python 项目初始化，尚未实现数据导入或分析功能。

## 本地运行（PowerShell）

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

运行后应输出：

```text
XHS Data Analyzer started.
```
